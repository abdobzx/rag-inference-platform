# Logging Service Documentation

## Overview
The Logging Service is a microservice designed to handle the collection, storage, and retrieval of logs generated by various components of the FastAPI microservices application. This service ensures that all logs are centralized, making it easier to monitor and debug the application.

## Features
- **Log Collection**: Collect logs from different services and store them in a structured format.
- **Log Retrieval**: Provide endpoints to retrieve logs based on various filters such as date, service name, and log level.
- **Scalability**: Designed to handle a growing amount of log data as the application scales.

## Architecture
The Logging Service is built using FastAPI and follows a microservices architecture. It communicates with other services through HTTP requests and can be deployed independently.

## Endpoints
- **POST /logs**: Accepts log entries from other services.
- **GET /logs**: Retrieves logs based on specified query parameters.

## Usage
To run the Logging Service, ensure that all dependencies are installed as specified in `requirements.txt`. Use the following command to start the service:

```bash
uvicorn src.main:app --host 0.0.0.0 --port 8000
```

## Dependencies
The required Python packages are listed in `requirements.txt`. Make sure to install them using:

```bash
pip install -r requirements.txt
```

## Best Practices
- Ensure that sensitive information is not logged.
- Implement log rotation and retention policies to manage disk space.
- Use structured logging for better searchability and analysis.
